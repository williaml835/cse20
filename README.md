## Save from Google Colab

1. Open the notebook in Colab and finish your edits.
2. Choose **File → Save a copy in GitHub**. Authorize GitHub if prompted.
3. Select **williaml835/cse20**, then **main**.
4. Use a path such as `notebooks/lectures/lecture-02-descriptive-topic.ipynb`.
5. Write a short commit message explaining the change and save.
6. Check the file on GitHub, then add its link to the lecture index above.

If direct saving is unavailable, download the `.ipynb` file from Colab and upload it into `notebooks/lectures/` on GitHub.

GitHub keeps the saved history; Colab runs and edits notebooks. Editing a Colab copy does not automatically update GitHub. Save again after each study session, and open the latest GitHub version when starting a new one.

## Naming and organization

- Use lowercase names, two-digit lecture numbers, and hyphens.
- Keep lecture notebooks in `notebooks/lectures/`.
- Put future personal study summaries in `notes/`.
- Keep unrelated projects in their own repositories.
- Check notebook outputs before saving; clear outputs containing personal data or credentials.
